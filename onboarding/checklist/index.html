費用與補助，先說清楚

課前準備（這份檢核表）有鐘點費嗎？
沒有。課前準備是你自己投入的——開信箱、裝工具、做安全檢查這些，你投入時間建立能力，卡米爾投入課程、工具範本與訂閱補助。它同時也是雙方確認合作默契的過程。
那正式上課呢？有鐘點費嗎？
有。課程總計約 3~6 小時，上課時數提供鐘點費。上課時數以 Ragic 線上打卡記錄，系統會依你各自的鐘點費自動計算（鐘點費因人而異）。
卡米爾補助什麼？
學習期兩個月的 Claude Pro 訂閱費。流程是「你先自行刷卡訂閱 → 再憑單據申請代墊款請款」，可請款的有兩筆：① 訂閱費的台幣實際消費金額 ② 該筆消費的國際交易手續費。請款四步驟如下：
  1. 下載 Claude 官方帳單——上面必須有卡米爾統編（Taiwanese VAT：70525198，即第 2 項的設定）。下載路徑：Account → Settings → Billing → Invoices／View → Download receipt
  2. 取得信用卡消費紀錄——紙本帳單或銀行 APP 截圖皆可，需清楚顯示這筆訂閱的台幣消費金額與國際交易手續費（建議遮蔽卡號與其他無關的消費明細）
  3. 合併成一份 PDF——上述兩份單據缺一不可，合併為單一 PDF 檔。檔名格式：日期_claude訂閱費NT$總額_電子帳單_姓名請款.pdf。例如消費金額 620 元＋手續費 9 元，檔名就是：
    2026-06-06_claude訂閱費NT$629_電子帳單_祐成請款.pdf
  4. 上傳雲端並回傳連結——用你的合作專用 Gmail（第 1 項）在 Google 雲端硬碟建立一個「請款專用」資料夾，共用權限設為「知道連結的任何人皆可檢視」，將 PDF 上傳後，把該檔案的雲端連結貼到群組，即完成代墊款請款申請
什麼時候撥款？請款有期限嗎？
撥款時間：每月月底前結算你當月提出的請款紀錄，於次月 5 日匯入你的兆豐銀行帳戶。
請款期限：以月份為單位，每筆消費須在消費當月起的三個月內提出請款，逾期不再受理。舉例：1/1 或 1/31 的消費紀錄，在 1～3 月之間提出都可以，到了 4 月就不能再申請。
什麼時候開始有報酬？
上課時數本身就有鐘點費（見上一題，Ragic 打卡計算）。完成課程後即具備領取任務的資格，正式承接任務並交付時，另依任務計酬。

建立合作專用 Gmail

約 5 分鐘 · 之後所有註冊都用它

在所有動作開始前，請先建立一個與卡米爾合作專用的 Gmail 信箱。好處有三個：工作與私人帳號分離、未來各服務間的連動授權更簡單、合作內容的往來紀錄集中好管理。

命名格式：cameo.你的代稱@gmail.com。以祐成自己為例，三種代稱取法都可以：

全名簡稱cyc →cameo.cyc@gmail.com
英譯名字yuchen →cameo.yuchen@gmail.com
英文名字joel →cameo.joel@gmail.com
重要 · IMPORTANT 接下來註冊 Claude（第 2 項）和 GitHub（第 3 項）時，請一律用這個 Google 帳號登入註冊，未來做連動授權設定會簡單很多。
回報：你的專用信箱地址（不用截圖，直接打字）
2

訂閱 Claude Pro

約 10 分鐘 · USD $20/月 · 月繳 · 填統編
  1. 前往 claude.ai，用第 1 項的專用 Google 帳號登入註冊
  2. 升級至 Pro 方案，注意付款週期的選擇（見下方說明）
  3. 在付款頁面的「Taiwanese VAT」欄位填入卡米爾統編：70525198
  4. 完成付款，確認可以正常對話
付款週期 · 請選月繳 訂閱頁面預設顯示的是 $17 USD / month（billed annually）——這是年繳方案，會一次收取整年費用。請切換成 Monthly（每月付款），畫面會變成 $20 USD / month，訂閱這個版本。原因：補助期為兩個月，月繳才能對上補助、也方便之後自行決定去留。
統編 · 關係到補助請款 「Taiwanese VAT」沒有填 70525198 的帳單，無法受理補助請款。如果付款時漏填，請截圖貼群組協助處理。
回報截圖：① Claude 設定頁顯示「Pro」方案 ② 帳單顯示月繳 $20 與統編
注意 · NOTICE Pro 的用量是「Claude 對話＋Claude Code」共用同一個額度，以 5 小時為一個窗口計算。跑大任務碰到限額是正常現象，等額度重置即可，不需要、也不要開啟任何加購功能（課堂會說明原因）。

註冊 GitHub

約 10 分鐘 · 用同一個 Google 帳號
  1. 前往 github.com，選擇以 Google 登入（Continue with Google），使用第 1 項的專用帳號

  3. 完成 email 驗證
  4. 開啟兩步驟驗證（Settings → Password and authentication）

安裝 Claude Code

約 15 分鐘 · 含金鑰自我檢查
  1. 安裝 Node.js（v18 以上）：到 nodejs.org 下載 LTS 版本
  2. 開啟終端機（Mac：Terminal／Windows：PowerShell），執行：
npm install -g @anthropic-ai/claude-code
  1. 執行 claude，依指示用你的 Claude Pro 帳號登入（選擇訂閱登入，不是 API）
  2. 看到 Claude Code 的歡迎畫面即成功
回報截圖：終端機顯示 Claude Code 已登入的畫面
自我檢查 · 關係到你的錢包 執行以下指令，確認結果是空白。如果有顯示任何內容，代表你的電腦設了 API 金鑰，Claude Code 會改走 API 計費而不是吃你的 $20 訂閱額度——請先回報群組處理。
MAC
echo $ANTHROPIC_API_KEY
WINDOWS POWERSHELL
echo $env:ANTHROPIC_API_KEY

系統安全基礎檢查

約 5 分鐘 · 用內建的就好，不要另裝
